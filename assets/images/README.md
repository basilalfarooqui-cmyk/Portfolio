# Images

Drop your photos in this folder using these exact filenames:

- `profile-photo.jpg` — used on the ID card and in the About section
- `project-hora.jpg` — HORA project thumbnail
- `project-smart-home.jpg` — Smart Home project thumbnail
- `project-rc-car.jpg` — Bluetooth RC Car project thumbnail
- `favicon.png` — browser tab icon

The HTML already points at these paths. Until a file exists its frame shows as a
tinted placeholder instead of a broken-image icon, so nothing looks broken.

Thumbnails are displayed small (about 104px wide) and cropped to 4:3, so anything
around 600×450 or larger is plenty. The profile photo is cropped to portrait.
